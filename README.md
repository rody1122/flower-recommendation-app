# Flower Recommendation App

## 概要

条件を選択すると、おすすめの花壇や寄せ植えを提案するWebアプリケーションです。

庭づくりを始めたいと思った際に、花の知識がなく何を選べばよいか分からなかった経験から、初心者でも使いやすいアプリを目指して制作しました。
これは職業訓練中に個人制作として開発したものです。

## 使用技術
- HTML
- CSS
- JavaScript
- jQuery（Ajax）
- JSON
- localStorage

## 主な機能
- 条件に応じたおすすめの表示
- JSONデータの読み込み
- お気に入り登録・削除
- localStorageによるお気に入り保持
- ページ間でのお気に入り同期
- 画像モーダル表示

## 工夫した点
- localStorageとstorageイベントを利用し、別ページでもお気に入り状態を同期
- 画像パスではなくIDでお気に入りを管理するよう改善し、データの整合性を向上
- 保存データの検証処理を追加し、不正データによる表示崩れを防止
- お気に入り一覧は同一タブで画面遷移するよう改善し、操作性を向上
